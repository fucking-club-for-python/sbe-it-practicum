# sbe-it-practicum
## 概要
情報実習の授業で作成したPythonコードおよび回路図を管理・共有するためのリポジトリです。

分かりにくいところはコメントで説明します。
> [!NOTE]
> 分からないところがあれば、口頭かissueで質問してください。
## ディレクトリ構成
```text
/
├── lesson{N}/
│   ├── *.py
│   └── 回路図.jpg
└── ...
```
各ディレクトリの役割は以下のとおりです。
| ディレクトリ・ファイル | 内容 |
|---|---|
| `lesson{N}/` | 授業で扱ったコード |
| `lesson{N}/回路図.jpg` | 授業で使用した回路図 |
